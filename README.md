# Yuze Wei — Academic Website

A single-file static academic website. Open `index.html` in a browser to preview.

## Customize
- Replace the placeholder final-report text in `index.html` with a link to your PDF.
- To link a local report, add `equidistribution-report.pdf` to this folder and use `<a href="equidistribution-report.pdf">Final Report (PDF)</a>`.
- To link your CV, add `cv.pdf` to this folder and link it from the CV section.
- Review project descriptions before publishing to ensure they accurately reflect your work.

## Publish with GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io` on GitHub.
2. Upload `index.html` and optional PDF files to the repository's root.
3. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/` once deployment finishes.

This website does not collect visitor data or use third-party scripts.
